# Pinned rules and card data

The engine targets one specific version of the Comprehensive Rules and one specific snapshot of
card data. They are updated together, deliberately, with an entry in the changelog below.

| What | Version | Location |
|---|---|---|
| Comprehensive Rules | Effective 2026-09-25 | `MagicCompRules-20260925.txt` (this folder) |
| Scryfall Oracle cards + rulings | *Not yet fetched (M0)* | `data/` (gitignored; run `tools/fetch_scryfall.py`) |

non-commercial.
